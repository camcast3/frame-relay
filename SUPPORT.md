# Support

## Questions and troubleshooting

Start with:

- [First multi-client test](./docs/user/first-multi-client-test.md)
- [Troubleshooting](./docs/user/troubleshooting.md)
- [Host and client setup](./docs/user/host-client-setup.md)
- [Deployment guide](./docs/user/deploy.md)

If the documentation does not resolve the issue, open a GitHub issue using the bug report form.
Include sanitized logs, exact commands, platform versions, and the relevant session settings.

Do not attach a real `.env`, SQLite database, screenshot containing private content, access token,
or unredacted network inventory.

## Security reports

Security vulnerabilities do not belong in support issues. Follow [SECURITY.md](./SECURITY.md).
